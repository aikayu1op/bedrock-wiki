Minecraft のサーバーを使うと、プレイヤーはオンラインまたはローカルエリアネットワーク経由で他の人と遊べます。
[公式 Mojang BDS ソフトウェアのダウンロードはこちら](https://www.minecraft.net/en-us/download/server/bedrock) です。

バニラの BDS に加えて、多くのコミュニティプロジェクトがさまざまな言語で存在します。
これらは Custom Server Software（Custom）と BDS-Based に分けられます。

サーバーソフトウェアの種類:

-   Custom Server Software = 完全にゼロから開発されたサーバーソフトウェア。
-   BDS-Based = BDS を基盤にして拡張・改変したサーバーソフトウェア。

BDS-Based に比べて Custom Server Software がかなり多いことに気づくかもしれません。この差にはいくつかの要因があり、特に大きいものは次のとおりです。

-   長い間、公式のサーバーソフトウェアが存在しなかったこと。BDS の最初のリリースは 2018 年 8 月 28 日で、Bedrock Edition の初期リリースである 2011 年から約 7 年後でした。
-   1.21.10 で Symbols（Mappings とも呼ばれます）が削除され、情報量を減らすために縮小された結果、多くの BDS-Based ソフトウェアが衰退したこと。
