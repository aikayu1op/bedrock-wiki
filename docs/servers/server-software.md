Minecraft のサーバーでは、プレイヤーがオンラインやローカルエリアネットワーク経由で他の人と一緒に遊べます。
[公式 Mojang BDS ソフトウェアのダウンロードはこちらです](https://www.minecraft.net/en-us/download/server/bedrock)。

バニラの BDS に加えて、多くのコミュニティプロジェクトがさまざまな言語で存在します。
これらのプロジェクトは、カスタムサーバーソフトウェア（Custom）と BDS ベースの 2 種類に分かれます。

サーバーソフトウェアの種類:

-   カスタムサーバーソフトウェア = 完全にゼロから開発されたサーバーソフトウェア。
-   BDS ベース = BDS を基盤にして拡張・改変したサーバーソフトウェア。

BDS ベースのソリューションに比べて、カスタムサーバーソフトウェアがかなり多いことに気づくかもしれません。この差にはいくつかの要因があり、特に大きいのは次の 2 つです。

-   長い間、公式のサーバーソフトウェアが存在しなかったこと。BDS の最初のリリースは 2018 年 8 月 28 日で、Bedrock Edition の最初のリリースである 2011 年から約 7 年後でした。
-   1.21.10 で Symbols（Mappings とも呼ばれます）が削除され、情報量を減らすために縮小された結果、多くの BDS ベースソフトウェアが衰退したこと。
