絵文字は Ore UI の画面ではサポートされていません。
:::
:::warning NINTENDO SWITCH
バニラ絵文字のテクスチャ変更は Nintendo Switch では互換性がありません。
:::

Minecraft には、ハードコードされた [Private Use ユニコード symbols](https://en.wikipedia.org/wiki/Private_Use_Areas) が多数あり、これらは自動的に絵文字のような記号に変換されます。
これらは、看板、本、アイテム名、チャットなど、通常の文字が使える場所ならどこでも使えます。

下には、プラットフォーム固有の絵文字と一般的な記号があります。
独自の絵文字を作る方法は [こちら](/text/custom-emojis) で学べます。

## 絵文字の使い方

多くの場所で、Minecraft は実際の文字の代わりに絵文字のショートコードを入力できます。
ただし、どこでも対応しているわけではないため、"文字" 列の文字を直接 Minecraft にコピー＆ペーストする必要がある場合があります。
